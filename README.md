# AutoDrive 🚗

AutoDrive is a full-stack vehicle management application designed to centralize vehicles, maintenance, expenses and reminders in one place.

## Project goals

The project is being built as a portfolio application with a production-oriented architecture and development workflow.

Planned features include:

- user authentication;
- vehicle management;
- maintenance history;
- fuel, insurance and repair expenses;
- maintenance and inspection reminders;
- dashboard with costs and usage statistics.

## Planned stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Data & infrastructure
- PostgreSQL
- Docker / Docker Compose

## Architecture

## Development approach

Features will be developed incrementally using Git branches and pull requests. The first milestone is a working end-to-end vehicle management flow backed by PostgreSQL.
